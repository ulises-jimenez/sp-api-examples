| Data element                                    | Substitute report                                                                      | Description                                                                                                        |
| ----------------------------------------------- | -------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------ |
| **Transaction ID / Order ID**                   | `GET_FLAT_FILE_ALL_ORDERS_DATA_BY_ORDER_DATE_GENERAL`                                  | Every order, with dates, customer country, status                                                                  |
| **Ship-from & Ship-to countries**               | `GET_AMAZON_FULFILLED_SHIPMENTS_DATA_GENERAL` (AFN)                                    | Contains both origin FC (warehouse) and destination address country — essential for determining cross-border flows |
| **Product price, quantity, totals**             | `GET_AMAZON_FULFILLED_SHIPMENTS_DATA_GENERAL`                                          | Net item value (before fees, before VAT)                                                                           |
| **Refunds / Returns**                           | `GET_V2_ALL_RETURNS_DATA_BY_RETURN_DATE` + `GET_FBA_FULFILLMENT_CUSTOMER_RETURNS_DATA` | Tells you which orders were refunded or returned and when                                                          |
| **Marketplace fees / commissions / net payout** | `GET_V2_SETTLEMENT_REPORT_DATA_FLAT_FILE_V2`                                           | For reconciling net receipts and validating totals                                                                 |
| **Inventory movements (to exclude transfers)**  | `GET_FBA_FULFILLMENT_INVENTORY_SUMMARY_DATA` or `Inventory Event Detail`               | Identifies SKUs moved between FCs (Pan-EU transfers)                                                               |
| **VAT rates / classification**                  | external lookup table                                                                  | You apply VAT rates per destination country and product category yourself                                          |
